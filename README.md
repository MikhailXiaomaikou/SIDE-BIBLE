# SIDE BIBLE · 正典之外

那些书页，从未沉默。

一座可游玩的古代文献剧场，灵感来自 [God Simulator](https://github.com/MikhailXiaomaikou/God-simulator)。在画面上按住，让书法逐字显影；松手，让故事展开。全屏的云、群山、湖岸、树木与飞鸟，陪你走过 **12 部作品、72 幕中文故事**。

![SIDE BIBLE 首页](docs/images/side-bible.png)

## 打开即读

下载本仓库的 **`index.html`**，用现代浏览器直接打开即可。它已经包含全部内容、样式、脚本和三套中文字体；无需安装、账号、联网或付费服务。原典链接需要联网访问。

也可在 Node.js 20 或更新版本的环境中运行：

```sh
npm start
```

然后打开 `http://127.0.0.1:4173/`。没有第三方依赖，不需要 `npm install`。

## 怎么玩

| 操作 | 效果 |
| --- | --- |
| 单击开启 / 继续上次阅读 | 进入书卷，恢复本机保存的位置 |
| 按住画面、显影按钮或空格，文字显完后松手 | 揭示一幕；提前松手取消 |
| 单击阅读 / 下一幕 | 不用长按，逐幕阅读 |
| 右键点击画面或正文 | 快速翻到下一幕，立即显示正文；弹窗内不翻页 |
| 书卷 / `B` | 按类别或关键词找故事，自由跳卷 |
| 幕次圆点 | 直接跳到该卷的一幕 |
| 拾页 / `L` | 回看读过的段落和收藏 |
| 原典与注记 | 查看章节、版本、所属传统与来源链接 |
| 声音 / `M` | 开关本地合成的环境音与钟音 |
| 全屏 / `F` | 浏览器允许时切换全屏 |
| 阅读说明 / `?` | 编选说明、快捷键与静谧模式 |
| `Esc` | 关闭窗口或取消显影 |

阅读位置、已读和收藏自动存于浏览器本机。移动 HTML 文件、改用其他浏览器或地址、清除浏览器数据，可能无法读取原来的记录。存储不可用时会显示提示，仍能完成本次阅读。页面支持触控、键盘、系统减少动态效果与暂停背景动画。

## 收录范围

| 类别 | 作品 |
| --- | --- |
| 远古与异象 | 以诺一书、禧年书、亚当与夏娃生平（希腊本／摩西启示录） |
| 智慧与拯救 | 多比传、犹滴传、所罗门智训 |
| 福音之外 | 雅各原福音、多马幼年福音、多马福音、马利亚福音、保罗与帖克拉行传、黑马牧人书 |

这里的“非正典”是项目的阅读入口，不是全体教会共享的一张排除名单。例如，多比、犹滴和所罗门智训属于天主教及东正教旧约；以诺一书和禧年书属于埃塞俄比亚正教正典。每卷单独说明，不将所有作品统称为“被禁止的圣经”。

**本项目是精选导读，不是这些文献的全文合集。** 中文旁白和显影短句为原创叙事改写，画面属于艺术演绎，不作为逐字经文引述；年代为概略范围，传统归属与文本形成并非同一问题。《马利亚福音》缺失的抄本页不补写。完整版本、场景定位与编辑原则见 [来源说明](docs/SOURCES.md)。

## 修改与验证

```sh
npm run build
npm test
git diff --check
```

`src/` 是可维护源码。修改它以后重新构建根目录 `index.html`，不要只修改生成文件。

```text
index.html             可离线打开的单文件成品
src/index.html         页面结构；HTTP 下可直接调试
src/style.css          响应式界面
src/content.js         12 卷、72 幕、来源和编辑说明
src/main.js            导航、长按、收藏与弹窗
src/state.js           进度、跳转、存档校验
src/world.js           原创 Canvas2D 场景
src/audio.js           原创 WebAudio 环境音
src/fonts/             离线中文字体子集、OFL 与来源清单
scripts/build.mjs      将源码内嵌成单文件
scripts/subset-fonts.py 按实际文字重建字体（仅改文字时需要）
scripts/serve.mjs      仅绑定本机的预览服务
tests/                内容、阅读流程、存档、构建和预览测试
docs/SOURCES.md        原典版本与来源
docs/VERIFICATION.md   实际验证范围
TASK.md               工作与交付记录
```
